## 질환과 목표로 시작하기

**새 연구**에서 질환·현상과 바꾸고 싶은 결과를 적습니다. 우선 검토할 접근을 고르고 **목표에서 연구 시작**을 누릅니다.

> 특발성 폐섬유증에서 폐 기능을 보존할 치료 연구 방향을 찾고 싶습니다.

조사할 질문과 비교할 설명, 필요한 자료와 도구 선택 이유를 살펴봅니다. 실행 중에는 연구별 상태와 현재 진행을 확인할 수 있습니다.

## 근거와 계산 확인하기

자료 제목에서 원출처를 열고, 논문·표·문단의 어느 위치를 읽었는지 확인합니다. 계산 결과에서는 **값·단위·실행 조건**과 원입력·원결과를 함께 봅니다. 후보 ID와 구조·서열이 후속 계산에서도 어떻게 이어지는지 따라갑니다.

사용한 추론 관점의 상세는 해당 실행에 전달된 원리와 허용된 근거 범위를 기준으로 표시됩니다. 적용 조건과 연결된 사례·출처를 연구의 현재 조건과 함께 검토합니다.

## 조건부 후보와 다음 실험 검토하기

**실험** 카드에서 구별할 설명, 대상·비교군·판독 지표·조건, 결과별 판단 변화를 확인합니다. 연결된 자료를 열어 후보와 비교를 제안한 이유를 읽습니다.

저장된 판단을 더 설명받으려면 **설명 물어보기**를 사용합니다. 이 요청은 실제 모델을 실행합니다.

## 관측을 더하고 재판단하기

**질문·조건·관측 추가**에서 결과와 출처·측정 조건을 적고 **초안 확인 → 확인하고 보내기**로 반영합니다. 문헌에서 가져온 관측과 직접 측정한 결과, 시연용 입력의 구분을 함께 남깁니다.

판단 이력에서 유지한 주장과 수정한 주장, 그 이유와 이어갈 행동을 비교합니다. 다른 기전을 검토하려면 **기전**에서 항목을 고르고 후속 검토를 접수합니다.

## 모델 경로 선택하기

새 요청의 기본 경로는 대회 API **GPT-6 Sol / medium**입니다. 사용량 한도로 HTTP 403 안내가 나오면 안내창에서 제출자 개인 구독 경로인 **Claude Opus 5 / medium 또는 GPT-6 Sol / medium**을 직접 고르고 확인합니다. 실제 연결 상태는 **모델 이용 안내**에서 볼 수 있습니다.

저장 연구·원자료 조회와 모델을 실행하는 질문·설명·후속 검토를 화면의 진행 상태와 함께 구분해 이용합니다. 공개할 수 있는 질문과 자료를 사용해 주세요.

## 보유 자료로 시작하기

후보 ID·SMILES를 담은 CSV나 유전자별 차등발현 결과 TSV를 화면의 양식에 맞춰 올릴 수 있습니다. 원자료와 계산 결과, 판단의 연결을 확인하며 같은 연구 루프를 이어갑니다.
